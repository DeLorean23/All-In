All-In Installer & Update for Batocera.

**New in v1.5:**
- Controllers are set up once in every emulator – no keyboard needed
- X11 mode, so pop-up windows can be used with the controller
- Region Europe / language German preset
- Hortensia no longer asks for the language
- Note: the first installation takes a while (SmileyTatsu and Hortensia)


**Download the ZIP below**, extract it to `/userdata` and start the installer from **Ports**.

Installs 10 Switch 2 emulators into one system "Switch 2":
- Eglantine (normal + PGO, default)
- Lichii (normal + PGO)
- Orchid (normal + PGO)
- Fritchii (Linux build by xTopher1049)
- Hortensia (combines many Eglantine forks in one build)
- Eglantine SmileyTatsu (normal + PGO, Mario Kart World)

Features:
- **Pick the emulator per game:** hold the button on a game → game options → **advanced game options** → emulator. The choice is saved for that game.
- **Controllers work right away:** connected controllers are set as players 1–8 in every emulator on each start, no keyboard setup (what was found is written to switch2.log)
- Option per game: start in fullscreen or in a window
- Same firmware, keys and saves for all emulators, own settings for each emulator
- Every emulator has its own entry under F1 → Applications
- Update by running the installer again: every emulator is checked on its own
- Takes over saves and settings of the old Eglantine Installer & Updater

Already installed an earlier download? Just run this installer once – it adds the new emulators – and answer the reboot question with yes.

Key files are only needed for Switch 1 files. No games, firmware or keys are included.
